# Entrega de validação do MVP EstudaIA

Este repositório contém os materiais de uma validação de produto para a disciplina de Metodologias Ágeis e Validação de Produtos.

## Escolha de experimento

Foi escolhido um concierge MVP de baixa fidelidade: a página gera uma simulação de plano de estudo de sete dias a partir do contexto informado pelo participante. Isso testa compreensão e intenção de uso antes de construir recursos como login, integrações, histórico ou uma IA conectada a dados acadêmicos.

## Estado da validação

O protótipo e o protocolo estão prontos. A etapa que exige cinco potenciais usuários reais não pode ser simulada com integridade acadêmica; as respostas devem ser registradas na matriz do DOCX após a aplicação do teste.
